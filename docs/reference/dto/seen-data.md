# Seen Data DTO Reference

The `NjoguAmos\Waha\Dto\SeenData` represents a request to mark messages as seen.

## `chatId` → `string`

The ID of the chat to mark as seen.

## `messageIds` → `array` or `null`

Optional array of message IDs to mark as seen.

## `participant` → `string` or `null`

Optional participant ID for group chats.
