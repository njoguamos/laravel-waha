# Session Config Gows Data DTO Reference

The `NjoguAmos\Waha\Dto\SessionConfigGowsData` contains configuration for the `GOWS` engine.

## `messages` → `bool`

Whether to store messages in the local storage.

## `groups` → `bool`

Whether to store groups in the local storage.

## `chats` → `bool`

Whether to store chats in the local storage.

## `labels` → `bool`

Whether to store labels in the local storage.
