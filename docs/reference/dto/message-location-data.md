# Message Location Data DTO Reference

The `NjoguAmos\Waha\Dto\MessageLocationData` represents a location message to be sent.

## `chatId` → `string`

The recipient's chat ID.

## `latitude` → `float`

The latitude of the location.

## `longitude` → `float`

The longitude of the location.

## `title` → `string`

The title/name of the location.

## `replyTo` → `string` or `null`

The ID of the message to reply to.
