# Message Update Data DTO Reference

The `NjoguAmos\Waha\Dto\MessageUpdateData` represents updated message content.

## `text` → `string`

The new text for the message.

## `linkPreview` → `bool`

Whether to include link previews. Default: `true`.

## `linkPreviewHighQuality` → `bool`

Whether to use high-quality link previews. Default: `false`.
