# Message Contact Vcard Data DTO Reference

The `NjoguAmos\Waha\Dto\MessageContactVcardData` represents a contact VCard message.

## `chatId` → `string`

The recipient's chat ID.

## `contacts` → `VCardContactData[]`

An array of contacts as VCards.

## `replyTo` → `string` or `null`

The ID of the message to reply to.
